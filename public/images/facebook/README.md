# תמונות לאתר

אפשר להוסיף תמונות בשתי דרכים:

## אופציה 1 — תיקיית `photos/` בשורש הפרויקט (הכי פשוט)

שים קבצים בשמות האלה בתיקייה `photos/` בשורש הפרויקט, ואז הרץ:

```bash
npm run sync-photos
```

| קובץ | שימוש |
|------|--------|
| `profile.jpg` | לוגו / תמונת פרופיל בכותרת ובאודות |
| `hero.jpg` | באנר ראשי בדף הבית |
| `gallery-1.jpg` … `gallery-3.jpg` | גלריה |
| `gallery-4.jpg` | אופציונלי — הופעה (אם חסר: `hero.jpg`) |

## אופציה 2 — ישירות כאן

שמור כאן (`public/images/facebook/`) או ב־`public/images/` באותם שמות, ורענן את האתר.

מקור מומלץ: [בקצב שלי בפייסבוק](https://www.facebook.com/MYRHITHM) → תמונות → שמירה בשם הקובץ מהטבלה למעלה.
