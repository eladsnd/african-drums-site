# תמונות מפייסבוק

שמור כאן תמונות מהדף [בקצב שלי בפייסבוק](https://www.facebook.com/MYRHITHM):

1. פתח את הדף → **תמונות** → **ראה את כל התמונות**
2. לחץ על תמונה → שמור בשם:

| קובץ | שימוש |
|------|--------|
| `profile.jpg` | לוגו / תמונת פרופיל (תמונת הפרופיל העגולה) |
| `hero.jpg` | באנר ראשי בדף הבית |
| `gallery-1.jpg` … `gallery-4.jpg` | גלריה |

אחרי השמירה, רענן את האתר (`npm run dev`).
