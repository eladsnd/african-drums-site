# מדריך ניהול האתר — Sanity Studio

מדריך קצר לעריכת תוכן האתר דרך `/studio`.

## כניסה

1. גשו לכתובת: `https://your-domain.co.il/studio`
2. התחברו עם Google / GitHub / אימייל (חשבון שקיבל הזמנה)

## מבנה התפריט

| פריט | מה עורכים |
|------|-----------|
| **הגדרות אתר** | שם, לוגו, צבעים, וואטסאפ, אימייל, רשתות חברתיות, פוטר |
| **דף בית** | כותרות, וידאו, טקסט קצר |
| **שיעורים** | סוגי שיעורים, מועדים, מחירון, קישור הרשמה |
| **סדנאות** | סדנאות קרובות + סדנאות פרטיות |
| **אודות** | ביוגרפיה, תמונת פרופיל |
| **המלצה** | ציטוטים של תלמידים (הוסיפו/מחקו פריטים) |
| **פריט גלריה** | תמונות וסרטונים |
| **פריט תקשורת** | קישורים לראיונות וכתבות |

## טיפים

- **תמונות**: לחצו Upload — Sanity דוחס ומגיש אוטומטית
- **וידאו**: העלו ל-YouTube, העתיקו קישור embed (למשל `https://www.youtube.com/embed/VIDEO_ID`)
- **שינויים**: נשמרים מיד — רעננו את האתר לראות
- **צבעים**: בהגדרות אתר → צבע ראשי / צבע רקע (HEX, למשל `#B45309`)

## מה לא לערוך

אל תשנו קוד — רק תוכן ב-Studio. לשינויי עיצוב/מבנה, פנו למפתח.

## בעיות?

- האתר לא מתעדכן? נסו Ctrl+Shift+R (רענון מלא)
- לא נכנס ל-Studio? ודאו שקיבלתם הזמנה ב-sanity.io/manage
- טופס יצירת קשר לא עובד? Formspree ID חייב להיות מוגדר ב-Vercel
