# מדריך לשלומי — עריכת האתר וסרטונים

## איך נכנסים

1. פתחו בדפדפן (במחשב או בטלפון):  
   **`https://כתובת-האתר-שלכם/studio`**
2. התחברו עם Google / Facebook / אימייל — לפי מה שהוזמנתם ב-Sanity.
3. בתפריט השמאלי בוחרים מה לערוך.

אם לא מצליחים להיכנס — בקשו מאלעד לשלוח הזמנה מחדש ל-sanity.io.

---

## מה אפשר לערוך

| בתפריט | מה משנים |
|--------|----------|
| **הגדרות אתר** | שם העסק, משפט קצר, לוגו, צבעים, וואטסאפ, אימייל, פייסבוק |
| **דף בית** | כותרות, **וידאו ראשי**, תמונת כיסוי, טקסט קצר |
| **שיעורים** | סוגי שיעורים, מועדים, מחירון, קישור הרשמה |
| **סדנאות** | סדנאות לילדים / מבוגרים / צרכים מיוחדים / אירועים |
| **אודות** | ביוגרפיה, תמונת פרופיל |
| **פריט גלריה** | תמונות **או** סרטונים מהעבודה |
| **המלצה** | ציטוטים אמיתיים מלקוחות (רק אם יש) |
| **פריט תקשורת** | קישורים לכתבות / ראיונות |

אחרי **Publish** (פרסום) — רעננו את האתר הרגיל (Ctrl+Shift+R) כדי לראות את השינוי.

---

## איך מעלים תמונות

1. **פריט גלריה** → **Create** (חדש)
2. **סוג** → **תמונה**
3. **תמונה** → לחצו **Upload** → בחרו קובץ מהטלפון/מחשב
4. **כיתוב** — משפט קצר (למשל «סדנת ילדים»)
5. **סדר** — מספר (1, 2, 3…) — קובע את סדר ההופעה בגלריה
6. **Publish**

אותו דבר ב-**הגדרות אתר** (לוגו) וב-**אודות** (תמונת פרופיל) וב-**דף בית** (תמונת כיסוי לוידאו).

## איך מעלים סרטונים (מומלץ: YouTube)

האתר **לא** מעלה קבצי וידאו כבדים ישירות — זה איטי ויקר.  
הדרך הפשוטה: **להעלות ל-YouTube** ולהדביק קישור ב-Studio.

### שלב א — העלאה ל-YouTube

1. היכנסו ל-[YouTube](https://www.youtube.com) (אפליקציה או אתר).
2. **צור** → **העלאת סרטון**.
3. בחרו את הסרטון מהגלריה בטלפון.
4. כותרת ותיאור — בעברית, לפי האירוע.
5. **נראות**:
   - **ציבורי** — כולם רואים ביוטיוב
   - **לא רשום** — רק מי שיש לו קישור (מתאים לאתר + שיתוף בפייסבוק)
6. חכו לסיום העלאה → **פרסם**.

### שלב ב — קישור באתר

**וידאו גדול בדף הבית**

1. Studio → **דף בית**
2. שדה **וידאו ראשי (YouTube)** — הדביקו את הקישור מ-YouTube  
   (הקישור הרגיל אחרי «שיתוף» מספיק — לא חייבים קישור מיוחד)
3. **תמונת כיסוי** — תמונה יפה שתופיע לפני שלוחצים Play (אופציונלי)
4. **Publish** → רעננו את דף הבית באתר

**סרטון בגלריה**

1. Studio → **פריט גלריה** → **Create**
2. **סוג** → **וידאו**
3. **קישור וידאו** — אותו קישור YouTube
4. **כיתוב** + **סדר** → **Publish**

### דוגמאות לקישורים שעובדים

- `https://www.youtube.com/watch?v=XXXXXXXX`
- `https://youtu.be/XXXXXXXX`
- `https://www.youtube.com/shorts/XXXXXXXX`

האתר יהפוך אותם אוטומטית לתצוגה מוטמעת.

### סרטונים מפייסבוק

פייסבוק לא תמיד נותן קישור הטבעה לאתר. הכי פשוט:

1. להעלות את אותו סרטון (או גרסה קצרה) ל-**YouTube** כמו למעלה, **או**
2. לפרסם בפייסבוק ולשים **באתר** רק תמונות — עם קישור לדף הפייסבוק.
