# תמונות לפני העלאה לאתר

שים כאן קבצים מהפייסבוק, ואז הרץ מהשורש:

```bash
npm run sync-photos
```

| קובץ | שימוש |
|------|--------|
| `profile.jpg` | תמונת פרופיל / לוגו (או `netlify.toml.jpg` אם כבר שמרת כך) |
| `hero.jpg` | באנר בדף הבית |
| `gallery-1.jpg` … `gallery-3.jpg` | גלריה |
| `gallery-4.jpg` | אופציונלי — הופעה / אירוע (אם חסר, משתמשים ב־`hero.jpg`) |
